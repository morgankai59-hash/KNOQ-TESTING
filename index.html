KNOQ.cc

Backups & privacy

This version stores records in this browser only. It does not sync devices. Export a backup regularly. Clearing browser/site data may delete your records.

Customer addresses and references may be sensitive. Follow your employer's data policies. Avoid entering customer addresses unless you're authorised to store them in this app. This prototype has no account login or cloud security.

KNOQ.cc configuration

Browser settings are local to this device. For staff accounts, secure syncing and administrator roles, deploy the included Supabase SQL and configure the public project URL/anon key. Never use a service-role key in this website.

Key must be restricted to your domain, with Maps JavaScript API and Geocoding API enabled. Keys visible to web browsers are not secret.

Only use a project with row-level security configured. See included setup guide and SQL.
